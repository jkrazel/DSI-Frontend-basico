# Sitio personal

Página personal de Juan Kraudy Zeledón, creada con HTML y CSS. Presenta información personal, intereses, una imagen y enlaces favoritos.

## Abrir el sitio

Abre `index.html` en tu navegador.

También puedes instalar la extensión **Live Server** en Visual Studio Code. Luego, haz clic derecho sobre `index.html` y selecciona **Open with Live Server** para abrir el sitio y ver los cambios al guardarlos.
